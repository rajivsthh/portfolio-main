## 🚀 Getting Started

### Prerequisites

- **Node.js** (v18 or higher)
- **npm** or **bun** package manager

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/rajivsthh/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   bun install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   # or
   bun run dev
   ```

4. **Open your browser**
   ```
   http://localhost:5173
   ```

### Build for Production

```bash
npm run build
# or
bun run build
```

The optimized files will be in the `dist/` directory.

### Preview Production Build

```bash
npm run preview
# or
bun run preview
```

## 🔒 Security Considerations

This portfolio demonstrates security-conscious development practices:

- ✅ **Type Safety** - TypeScript for compile-time error prevention
- ✅ **Input Validation** - Zod schemas for runtime validation
- ✅ **Secure Links** - `rel="noopener noreferrer"` on external links
- ✅ **Dependency Management** - Regular updates and security audits
- ✅ **CSP Ready** - Content Security Policy compatible structure
- ✅ **No Sensitive Data** - Environment variables for configurations

## 📊 Performance

- ⚡ **Fast Load Times** - Optimized bundle sizes with code splitting
- 🎯 **Tree Shaking** - Removes unused code automatically
- 📦 **Lazy Loading** - Components loaded on demand
- 🖼️ **Asset Optimization** - Compressed images and resources

## 📝 Customization

To customize this portfolio for your own use:

1. Update personal information in component files
